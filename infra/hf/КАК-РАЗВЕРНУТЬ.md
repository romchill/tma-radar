# Как включить круглосуточную работу

Сейчас радар живёт на ноутбуке: выключил — заказы не приходят. Эта инструкция
переносит его на бесплатный хостинг, где он работает всегда и приложение
открывается по постоянному адресу.

Карта не нужна нигде. Ни на одном шаге.

## Из чего это собрано

| Что | Кто делает | Зачем |
|---|---|---|
| **Neon** | бесплатная база данных | хранит лиды и настройки; на хостинге диск сбрасывается при перезапуске, поэтому база вынесена наружу |
| **Hugging Face Space** | бесплатный хостинг | круглосуточно крутит радар и отдаёт мини-апп по адресу `https://<аккаунт>-tma-radar.hf.space` |
| **GitHub** | хранит код | при каждом изменении сам выкатывает его на хостинг и раз в 15 минут будит Space, чтобы тот не засыпал |

## Что нужно сделать руками

Две регистрации. Обе — по почте или через GitHub, карту не спрашивают.

### 1. База данных

1. Открыть <https://neon.com> → **Sign up** (проще всего кнопкой «Continue with GitHub»).
2. Создать проект, имя любое, регион — ближайший к Европе.
3. На главной странице проекта найти **Connection string** и нажать «копировать».
   Строка выглядит так:
   `postgresql://имя:пароль@ep-что-то.eu-central-1.aws.neon.tech/neondb?sslmode=require`
4. Прислать её мне.

### 2. Хостинг

1. Открыть <https://huggingface.co/join> → зарегистрироваться.
2. Зайти в <https://huggingface.co/settings/tokens> → **Create new token**.
3. Тип токена — **Write** (не Read: иначе выкатывать код будет нечем).
4. Скопировать токен (он показывается один раз) и прислать мне.

Всё. Остальное — создание Space, настройка секретов, первая выкатка и
проверка — делается за тебя.

## Что будет после

- Заказы прилетают в телеграм всегда, даже когда ноутбук выключен.
- Мини-апп открывается по постоянному адресу, кнопки в старых сообщениях
  больше не протухают.
- Туннель с ноутбука становится не нужен.
- Docker на ноутбуке можно не запускать вовсе — он нужен только если захочется
  что-то поменять и проверить до выкатки.

## Про безопасность

Репозиторий открытый, но токен бота, пароль базы и ключ ВК в него не попадают:
они лежат отдельно в секретах GitHub и Hugging Face, в коде их нет.

Адрес мини-аппа будет публичным, однако все ручки требуют подписанный Telegram
initData, а user id обязан входить в `ADMIN_IDS`. Посторонний, открыв адрес,
увидит пустую страницу.
